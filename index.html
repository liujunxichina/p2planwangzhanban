为什么选择 P2P LAN？

传统内网穿透要么要买 VPS，要么要配置路由器端口映射。P2P LAN 两者都不要。

🛰️

零服务器

基于 Hyperswarm DHT 分布式网络发现对端，没有任何中心化服务器，也不会被单点故障影响。

🔀

NAT 穿透

UDP Hole Punching 自动打洞，无需路由器端口映射。严格 NAT 环境自动回退 DHT 中继。

🔐

端到端加密

Noise 协议加密所有流量，数据只在你和对方之间传输，中间任何人都无法窃听。

🧵

流多路复用

单条 P2P 连接承载多个 TCP 流，多个朋友可同时加入，互不干扰。

它是如何工作的？

房间号经 SHA-256 派生为 DHT Topic，双方加入同一 Topic，通过 UDP 打洞建立加密直连。

常见问题

需要公网 IP 或 VPS 吗？▾

不需要。完全基于 DHT 的 P2P 发现和 UDP Hole Punching，零服务器、零配置。

两边都是严格 NAT 怎么办？▾

Hyperswarm DHT 内置中继节点，会自动回退到 DHT Relay 模式。速度会慢一些，但仍然可用。

支持多少朋友同时在线？▾

理论上无限。隧道使用 Stream ID 多路复用，每个 TCP 连接分配独立 ID，多人可同时连接互不干扰。

速度怎么样？▾

无人工限速，瓶颈在主机上行带宽。Minecraft 联机每个玩家仅需约 100 Kbps。

需要安装依赖吗？▾

不需要。Windows 版为绿色免安装，解压后直接运行 P2P-LAN.exe 即可，无需 Node.js 等任何环境。
